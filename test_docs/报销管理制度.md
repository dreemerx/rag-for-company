# XX科技有限公司费用报销管理制度

**文件编号：FIN-2025-001**
**版本：V1.2**
**生效日期：2025年1月1日**

---

## 第一章 总则

### 第一条 目的

为规范公司费用报销管理，加强财务内部控制，合理控制费用支出，特制定本制度。

### 第二条 适用范围

本制度适用于公司全体员工的费用报销管理。

### 第三条 基本原则

1. **真实性原则**：报销费用必须真实发生
2. **合规性原则**：符合国家法律法规和公司制度
3. **及时性原则**：费用发生后应及时报销
4. **节约性原则**：厉行节约，反对浪费

## 第三章 报销流程

### 第九条 报销时间

1. **日常费用**：每周二、周四集中报销
2. **差旅费用**：出差返回后5个工作日内
3. **月度费用**：次月10日前
4. **跨年费用**：次年1月15日前

### 第十条 报销流程

```
填写报销单
    ↓
粘贴发票
    ↓
部门主管审批
    ↓
财务审核
    ↓
（5000元以上需总经理审批）
    ↓
出纳付款
```

### 第十一条 报销单填写

1. **必填项**：
   - 报销人姓名、部门
   - 费用类型
   - 费用发生日期
   - 费用金额
   - 费用事由

2. **附件要求**：
   - 发票（增值税专用发票或普通发票）
   - 行程单（差旅费）
   - 审批单（招待费、培训费等）

### 第十二条 发票要求

1. 发票抬头必须为公司全称：**XX科技有限公司**
2. 纳税人识别号：91110108MA12345678
3. 发票内容真实、完整、清晰
4. 发票日期在报销期限内
5. 电子发票需打印后报销

## 第四章 特殊费用

### 第十三条 培训费

1. 单次培训费2000元以下：部门经理审批
2. 单次培训费2000-10000元：总监审批
3. 单次培训费10000元以上：总经理审批
4. 需签订《培训服务协议》

### 第十四条 团建费

1. 标准：每人每年2000元
2. 审批：部门经理审批
3. 用途：聚餐、旅游、拓展等
4. 报销：凭发票，注明参与人员

### 第十五条 加班餐费

1. 工作日加班超过20:00，可报销晚餐30元
2. 需在系统中提交加班申请并获批
3. 凭发票报销，注明加班日期

### 第十六条 加班交通费

1. 工作日加班超过22:00，可报销打车费
2. 需在系统中提交加班申请并获批
3. 报销范围：公司至住所的合理路线

## 第五章 审批权限

### 第十七条 审批额度

| 审批人 | 审批额度 | 说明 |
|--------|----------|------|
| 部门经理 | 2000元以下 | - |
| 总监 | 2000-10000元 | - |
| 副总经理 | 10000-50000元 | - |
| 总经理 | 50000元以上 | - |

### 第十八条 审批时限

1. 审批人应在2个工作日内完成审批
2. 超时未审批，系统自动提醒
3. 紧急费用可先口头审批，后补流程

---

## 第六章 违规处理

### 第十九条 违规行为

1. 虚报、冒领费用
2. 伪造、变造发票
3. 超标准报销未审批
4. 超期报销未说明原因

### 第二十条 处理措施

1. **第一次违规**：警告，退回违规金额
2. **第二次违规**：记过，退回违规金额，扣发当月绩效
3. **第三次违规**：解除劳动合同
